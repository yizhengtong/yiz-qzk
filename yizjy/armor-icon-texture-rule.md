# 护甲装备物品图标生成规则（最终版）

> 给 Minecraft 护甲套（头盔/胸甲/靴子）生成 16×16 物品图标的标准流程。素材工具：`D:\ZM\GUI积木工具包`，母模板在 `C_母模板/`，套装备份在 `D:\ZM\yizgzq\方块\强化\套装\<套装名>\`（每套子目录含 bbmodel + 生成的 3 张图标）。

## 母模板是「包边圈」

`C_母模板/头盔.png`、`胸甲.png`、`靴子.png` 是**物品的包边轮廓**（不是实心剪影）：
- **亮灰 `L`(45)** = 包边（最外圈），**深灰 `D`(25)** = 主体区域
- 语义：**圈内 + 圈本身 = 可工作区，圈外必须保持透明**（绝不能画出圈）

## 配色：按部位独立取色

从各套装自己的 **bbmodel 穿戴层纹理**（`armor_layer_1`，64×32，内嵌 base64）取色：
1. 从 bbmodel 元素解析各部位 UV 区域（head/body/shoe/arm），**layer_1 + layer_2 两个元素要用并集合并**（否则 layer_2 的 uv 偏移会覆盖 layer_1）
2. 各部位区域（标准 64×32 布局）：
   - 头盔 head：x0-32, y0-16
   - 胸甲 body：x16-40, y16-32
   - 靴子 shoe：x0-16, y16-32
   - 护肩 arm：x40-56, y16-32
3. 对每个部位区域用 **k-means 聚类 8 色**（按颜色距离，能保留不同色系，比亮度分档好）
4. **头盔 ← head 配色**、**靴子 ← shoe 配色**、**胸甲主体 ← body 配色**

## 胸甲包边：肩部两点 RGB 分上下

胸甲的**包边（外圈轮廓）**不用 body 色，而是用护肩位置的两个像素 RGB：
- **上包边 = 穿戴纹理 (45,20) 的 RGB**
- **下包边 = 穿戴纹理 (45,24) 的 RGB**
- 包边像素：`y < 中心线` 用上包边色，`y >= 中心线` 用下包边色（上下明暗层次）
- 胸甲主体内部仍用 body 配色渐变

## 生成流程（每件）

1. BFS 从边界透明像素标记「外部」，圈 + 圈内 = 工作区
2. **圈边界**（8 邻域含圈外的像素）→ 包边色（胸甲分上下，头盔/靴子用该部位 palette 暗端）
3. **圈内** → 部位 palette 插值：`bright = 0.28 + (1-vf)*0.52 - dist*0.20`，clip [0,1]
4. **头盔特殊**：先画头盔主体，**完工时把 `C_母模板/阴影.png` 覆盖到上层**（阴影是覆盖层，不是底层）；胸甲/靴子不叠
5. 圈外保持透明

## 踩过的坑

- `fill_material`（GUI积木工具包源码）对**稀疏/空心轮廓**不适用：位置着色会把所有像素判成边缘 → 全深色。需自己实现「圈边界描边 + 圈内渐变」
- 母模板内部原本是空的，必须先 BFS 填满圈内才算工作区
- **layer_1 + layer_2 双元素**必须并集合并（最初因覆盖导致头盔取色区跑到透明区）
- **阴影层叠放顺序易搞反**：先生成主体 → 完工覆盖阴影（不是阴影垫底）
- 胸甲肩部位置以用户指定为准：**(45,20)(45,24) 两点直接取 RGB**，不要区域提取
