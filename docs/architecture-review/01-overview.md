# YizMod QZK 架构评价概览

**评价日期**: 2026-05-19  
**项目**: YizMod QZK (NeoForge 1.21.1 库模组)  
**MODID**: `yizmodqzk`

## 项目定位

本项目是一个**前置库模组 (Library Mod)**，为下游模组提供伤害/效果/健康修改/统一UI框架。核心设计理念是"提供一个统一入口"——所有下游模组的伤害逻辑、天赋展示（PlayerTalentUI）、物品信息展示（ItemInfoUI）都通过本库汇聚，避免生态割裂。类比：JEI 统一物品列表，本库统一天赋/词缀/随影展示面。

## 架构强项

1. **API Facade 设计** — `YizModQZKAPI` 全静态方法，下游零依赖/零注入即用
2. **多层防御体系** — 健康修改 (3层+1保底)、禁疗 (3层)、保护态 (5层)
3. **Mixin 克制** — 仅 3 个 Mixin，重逻辑在 Agent 和事件层
4. **6 维度效果框架** — 感知/激活/父类型/稀有度/解锁/执行，清晰分包
5. **统一 UI 面板** — PlayerTalentUI + ItemInfoUI，所有下游模组效果自动汇聚

## 架构弱项

1. **EntityASMUtil 神类** — 345 行揉合 delta管理/禁疗/ASM回调/Agent状态/伤害效果等 8 项职责
2. **网络同步缺失** — UnlockManager 为纯服务端内存存储，客户端天赋面板无法获取数据
3. **武器系统死代码** — 初始提交自动生成的 `weapon/` `talent/` 包无人使用（已于本次审查中清理）
4. **UI 渲染每帧 O(n)** — getPlayerTalents() 每帧遍历全部已注册效果
