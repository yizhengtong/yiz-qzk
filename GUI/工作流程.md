# AI 工作流程 — 积木化建造 SOP

> AI 通过裁剪工具的 HTTP API（端口 19732）直接操作图片。
> 前提：用户已启动 `图片裁剪工具.exe`，并选好了保存目录和图片文件夹。

---

## 四区目录说明

| 目录 | 定位 | AI 操作 |
|------|------|---------|
| `A_通用/` | 所有 GUI 必用积木 | **只读引用**，不修改 |
| `B_功能/` | 功能型/容器专属积木 | **只读引用**，不修改 |
| `C_已完成/` | 翻译完毕的备份归档 | 写入副本 |
| `D_生成/` | AI 局外生成的图片 | **写入新图** |

---

## 两种工作模式

### 局内拼凑（引用已有积木）

用户描述需求 → AI 查翻译目录 → 从 A_通用/B_功能 选积木 → 生成代码引用路径。

**不生成新图片，只引用已有文件。**

### 局外生成（API 绘制新图）

用户描述需求 → AI 找到模板 → `/api/fill` 填色 → 保存到 `D_生成/` → 更新翻译目录。

**生成新图片文件，存入 D_生成。**

---

## 流程总览

```
用户表达需求
      ↓
  ┌── 需要新图？─── 否 ──→ 局内拼凑：查目录→引用路径→生成代码
  │
  │   是
  │    ↓
  │  查翻译目录：有现成模板？
  │    ├── 有 → /api/open 模板 → /api/fill 填色 → D_生成/
  │    └── 无 → 用户提供模板 / 从其他图裁剪
  │    ↓
  │  保存到 D_生成/ → 更新 翻译目录.md → 告知用户
  │
  ↓
  C_已完成/ 备份归档
```

## Phase 1: 扫描

```
POST /api/files
→ 返回: {"files": ["border_corner_tl.png", "empty_slot_sword.png", ...]}
```

AI 拿到文件列表，按文件名初步分类：
- `border_*` `fill_*` `slot_*` `player_*` `split_*` `scroll_*` `search_*` → 疑似 A_通用
- `brewing_*` `anvil_*` `smithing_*` `enchanting_*` `empty_*` `process_*` `result_*` → 疑似 B_功能
- 无法判断 → Phase 2 确认

---

## Phase 2: 识别

对每个文件调用：

```
POST /api/open      {"path": "图片完整路径"}
POST /api/preview   {}
→ 返回: {"size": [w,h], "ascii": [" 111","1  1",...], "cell": 1}
```

AI 读 ASCII 色块，判断：
1. **是不是深灰剪影模板？**（只有 `1` / `0` 两种深度，背景透明）
   → 是 → 进入 Phase 4 填色
   → 否 → 判定为成品积木，直接分类

2. **是什么类型的积木？**
   - 18×18，深灰边框+灰底+白边 → 槽位类
   - 5×5，L 形渐变 → 边角类
   - 1×N 或 N×1，单色 → 边条类
   - 大面积纯色 → 填充类
   - 162×76 → 玩家背包
   - 含 r（红色）像素 → 功能性特征积木

---

## Phase 3: 分类

```
是强制通用积木？
  ├── fill_white, border_*, slot_default, player_slots_9x4, split_bar
  │   → A_通用/（必须）
  │
  ├── scroll_bar, scroll_thumb, search_box
  │   → A_通用/（高度复用，虽非每个 GUI 都用到）
  │
  └── 其他（brewing_*, anvil_*, smithing_*, enchanting_*, empty_*, process_*, result_*）
      → B_功能/
```

**关键判断**：这个积木会不会出现在 ≥2 个不同的 GUI 中？
- 是 → 可考虑放入 A_通用
- 否 → B_功能

---

## Phase 4: 填色（仅模板类）

当图片是深灰剪影（如 `empty_slot_sword.png`）时：

### 4.1 用户指定配色方案

用户说："把这把剑做成钻石剑的颜色" →
AI 查询知识库，钻石剑配色：剑身 `#5CE1D6`，剑格 `#6B6B6B`，剑柄 `#5D4037`

### 4.2 分区域填色

```
方案 A：整图统一染色
POST /api/fill  {"to": [92, 225, 214, 255], "tolerance": 60}
→ 所有非透明像素变为青色

方案 B：分区域填色（更精细）
POST /api/fill  {"to": [92, 225, 214, 255], "x":0, "y":0, "w":16, "h":9}   ← 剑身
POST /api/fill  {"to": [107, 107, 107, 255], "x":0, "y":9, "w":16, "h":3}  ← 剑格
POST /api/fill  {"to": [93, 64, 55, 255],   "x":0, "y":12, "w":16, "h":4}  ← 剑柄
```

### 4.3 按像素精确填色

```
POST /api/fill  {"from": [56, 56, 56, 255], "to": [92, 225, 214, 255], "tolerance": 5}
→ 只替换指定的深灰像素，不碰其他颜色
```

### 4.4 批量生成变体

一个剑模板 → 多种材质的剑：

```
铁剑:   /api/fill {"to": [136, 136, 136, 255]}  → 保存 iron_sword.png
金剑:   /api/fill {"to": [250, 218, 72, 255]}   → 保存 golden_sword.png
钻石剑: /api/fill {"to": [92, 225, 214, 255]}   → 保存 diamond_sword.png
```

---

## Phase 5: 保存

```
POST /api/save        → 保存全图（用命名清单中的文件名）
POST /api/save_sel    → 保存选区（同上）
```

带命名清单的保存：
1. 先通过 `/api/load_list` 加载翻译清单
2. 每次 `/api/save` 或 `/api/save_sel` 自动使用清单中的文件名
3. 保存后自动推进到清单的下一项

或直接指定路径：
```
POST /api/set_dir  {"dir": "D:/.../A_通用/"}
→ 后续 save 都存到这个目录
```

---

## Phase 6: 记录

每完成一个积木块的处理，AI 必须同步更新文档：

### 6.1 更新翻译目录.md

在对应分类下追加：
```markdown
### 新文件名.png
- **尺寸**: W×H | **类别**: [槽位/边框/...]
- **用途**: [AI 推断或用户确认的用途]
\```
[ASCII 色块预览]
\```
```

### 6.2 更新风格标签.md

如果是 B_功能/ 的新图标：
```markdown
| `新文件名.png` | [造型] | [气质] | [适用场景] | [关键词] |
```

### 6.3 不要重复

更新前先检查 `翻译目录.md` 是否已有同名条目 → 有则更新，无则追加。

## 完整实操示例

```
用户："帮我把 empty_slot_sword.png 做成铁剑、金剑、钻石剑三个版本"

AI 执行：
  POST /api/open     {"path": "D:/.../empty_slot_sword.png"}
  POST /api/preview  {} → 确认是深灰剪影，16×16

  铁剑：
  POST /api/fill     {"to": [136,136,136,255], "tolerance":60}
  POST /api/set_dir  {"dir": "D:/.../B_功能/"}
  POST /api/save     → 保存为 iron_sword.png（如清单中指定）

  撤销回模板：
  Ctrl+Z（或 /api/open 重新加载模板）

  金剑：
  POST /api/fill     {"to": [250,218,72,255], "tolerance":60}
  POST /api/save     → golden_sword.png

  钻石剑：
  POST /api/fill     {"to": [92,225,214,255], "tolerance":60}
  POST /api/save     → diamond_sword.png

  记录：
  在 翻译目录.md B_功能/ 下追加三条条目
```

## API 速查

| 端点 | 用途 | 关键参数 |
|------|------|---------|
| `/api/state` | 查看当前状态 | — |
| `/api/files` | 列出图片文件夹 | — |
| `/api/preview` | ASCII 色块预览 | — |
| `/api/open` | 打开图片 | `path` |
| `/api/select` | 设置选区 | `x,y,w,h` |
| `/api/fill` | 填色替换 | `to:[r,g,b,a]`, `from`(可选), `tolerance`, `x,y,w,h`(可选) |
| `/api/save` | 保存全图 | — |
| `/api/save_sel` | 保存选区 | — |
| `/api/crop` | 裁剪到新标签 | — |
| `/api/remove` | 移除选区像素 | — |
| `/api/mode` | 切换模式 | `mode: select/move/magic` |
| `/api/load_list` | 加载命名清单 | `path` |
| `/api/set_dir` | 设置保存目录 | `dir` |
| `/api/set_img_folder` | 设置图片文件夹 | `dir` |

端口：`19732` | 协议：HTTP POST + JSON
