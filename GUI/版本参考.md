## 1. isHovering 源码

文件: `AbstractContainerScreen.java` 第 637–650 行

```java
protected boolean isHovering(int x, int y, int width, int height,
                              double mouseX, double mouseY) {
    int i = this.leftPos;
    int j = this.topPos;
    mouseX -= (double)i;
    mouseY -= (double)j;
    return mouseX >= (double)(x - 1)        // ← 命中盒起点 = slot.x - 1
        && mouseX < (double)(x + width + 1)
        && mouseY >= (double)(y - 1)
        && mouseY < (double)(y + height + 1);
}
```

**关键**：`x - 1` 和 `y - 1` 是硬编码的偏移。如果新版 Minecraft 改了这两个值，整个 1px 偏移规则需重新评估。

## 2. containerId 修复 — 完整代码

文件: 自定义 Screen 类

```java
// 单机模式通过集成服务端打开容器
Minecraft mc = Minecraft.getInstance();
if (mc.hasSingleplayerServer()) {
    MinecraftServer server = mc.getSingleplayerServer();
    ServerPlayer sp = server.getPlayerList()
        .getPlayer(mc.player.getUUID());
    if (sp != null) {
        sp.openMenu(new SimpleMenuProvider(
            (containerId, playerInv, player) ->
                new MyContainerMenu(containerId, playerInv),
            Component.literal("Container Title")
        ));
        return true; // 服务端会发送 ClientboundOpenScreenPacket
    }
}
return false;
```

**原理**：服务端分配真实 containerId → 发 `ClientboundOpenScreenPacket` → 客户端自动打开对应 Screen → 槽位点击正常。

## 4. render() 调用链

`AbstractContainerScreen.render()` 内部执行顺序：

```
render() {
    renderBg(...);       // ← 调用你的 override
    super.render(...);   // ← 渲染槽位、物品、tooltip
}
```

因此你只需 override `renderBg()`，不需碰 `render()`。
