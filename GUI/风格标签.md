# GUI 功能图标 — 风格标签系统

> AI 选图决策规则：根据用户描述的关键词，匹配对应风格的图标。
> **核心原则**：像素资源有限，同一图标可在不同 GUI 语境下承载不同语义。
> 多重语义定义 → 详见 `翻译目录.md`

---

## 图标的多重语义原则

因为纹理资源是有限的，同一张图在不同 GUI 位置可以表达不同含义：

```
strength.png
  ├── 在药水效果 HUD → "力量效果激活"
  ├── 在属性面板     → "攻击力" / "物理伤害"
  ├── 在武器对比     → "伤害值" / "DPS"
  └── 在技能树       → "力量属性点"
```

**AI 选图逻辑**：不是"这个图标是什么"，而是"在这个 GUI 语境下，这个图标表达什么"。

1. 根据用户描述的 GUI 类型确定语境
2. 在翻译目录中查找该语境下最匹配的语义
3. 如果一张图覆盖多个需要的语义 → 优先使用它（减少纹理数量）

每个功能图标标注四个维度的标签：

| 维度 | 含义 | 示例值 |
|------|------|--------|
| **功能** | 这个图标干什么 | `翻页` `确认` `关闭` `搜索` |
| **造型** | 视觉形态 | `三角形` `弯钩` `十字` `箭头` |
| **气质** | 给人的感觉 | `锐利现代` `古朴沉浸` `中性通用` |
| **适用场景** | 适合什么风格的 GUI | `科技风` `魔法书` `工业` `通用` |

**AI 决策规则**：
- 用户说"科技/现代/HUD/终端/科幻" → 选三角形
- 用户说"古朴/魔法/RPG/中世纪/书" → 选弯钩
- 用户没有指定风格 → 默认选三角形（常规实用型）

## AI 选图决策流程

```
用户描述 → 提取关键词 → 匹配标签 → 输出推荐

"我要一个科技感的酿造GUI"
  → 关键词: 科技感
  → 翻页类选 triangle_next（三角形/现代）
  → 进度类选 bar_simple（矩形/现代）
  → 关闭类选 cross_thin（细线/极简）
  → 通用部分照常: border_*, slot_default, player_slots

"我要一个魔法书GUI"
  → 关键词: 魔法书
  → 翻页类选 page_curl_next（弯钩/古朴）
  → 确认类选 seal_stamp（印章/正式）
  → 关闭类选 cross_ornate（装饰/古典）
  → 通用部分照常
```

## 新增图标的标注规范

每次往 B_功能/ 加入新图标时，必须在此文件中追加风格标签条目：

```markdown
### [功能名]类

| 文件名 | 造型 | 气质 | 适用场景 | 关键词匹配 |
|--------|------|------|---------|-----------|
| `xxx.png` | [形状描述] | [感觉描述] | [适合什么 GUI] | [触发关键词] |
```
