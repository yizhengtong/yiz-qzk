# 材质配色指南 — 色彩风格参考

> 非对齐原版色。而是学习原版的**藏色风格**（明暗结构 + 色彩搭配比例），
> 用自己的配色方案创造新材质。

---

## 核心原则

原版的"好看"不是因为颜色本身，而是因为：

1. **每个材质 8~11 个颜色** — 远多于"深中浅"三色
2. **亮度范围跨度大** — 最暗 ~20，最亮 ~255
3. **高光不是纯白** — 暗色调材质（下界合金）最亮才 130
4. **颜色分布有规律** — 26% 轮廓 | 26% 暗面 | 36% 主体 | 12% 高光
5. **多色过渡不是阶梯式** — 相邻亮度差值在 20~50 之间，不是等距

---

## 明暗结构（不是颜色，是灰度）

原版每把剑都遵循相同的亮度结构。这是**用 ref_path 保留的结构**：

### 亮度分布比例（84px 剑）

| 层次 | 像素占比 | 约多少像素 | 描述 |
|------|:-------:|:---------:|------|
| Outline（轮廓） | 26% | ~22px | 外缘最深色 |
| Shadow（暗面）+ Handle | 26% | ~22px | 暗面过渡+手柄深色 |
| Body（主体） | 36% | ~30px | 多个中间色 |
| Highlight（高光） | 12% | ~10px | 受光面亮色 |

**关键**：这个比例就是 `fill_material` 的 ref_path 结构。把 `iron_sword.png` 当底模，只换色相不换亮度——原版怎么分几层暗几层亮，新的就是几层。

### 亮度阶梯模式

原版武器的亮度递增不是等距的，而是：

```
亮度范围: [最暗 ~20] → [手柄 ~45/70] → [暗面 ~90/110] → [主体 ~130/160/190] → [高光 ~220/255]
差值:          25          45          40          50          35
```

**规律**：轮廓→暗面跨度小（细节多），暗面→主体跨度大（对比强），主体→高光跨度中等（高光不突兀）。

## 色彩搭配规则（不是色值表）

### 规则 1：一组材质主色，配一组手柄色（固定）

```
[材质色]                        [手柄色] ← 所有武器共用
  ┌── 轮廓: 主色 × 0.2            outline: #281e0b
  ├── 暗面: 主色 × 0.5            shadow:  #493615  
  ├── 主体: 主色 × 0.7 ~ 1.0      body:    #684e1e
  ├── 主体亮: 主色 × 1.15          highlight: #896727
  └── 高光: 主色 × 1.35
```

手柄色**不随材质变化**。

### 规则 2：冷色调配冷高光，暖色调配暖高光

```
材质色调 → 高光色倾向
冷色（蓝/青/紫）→ 高光偏冷白（#d0e8ff / #c0fffa）
暖色（红/橙/棕）→ 高光偏暖白（#fff0d0 / #ffd0c0）
中性（灰/黑）   → 高光偏中性白（#f0f0f0）
```

### 规则 3：低亮材质 <u>不设亮高光</u>

```
材质整体亮度     → 高光亮度
高（钻石/金）    → 200~255
中（铁/石）      → 180~220
低（下界合金）   → 100~140
暗（暗黑/熔岩）  → 80~110
```

下界合金最亮才 130，如果给下界合金配 255 的高光就会失去厚重感。

### 规则 4：颜色数量 = 材质深度

| 颜色数 | 效果 | 适合 |
|:-----:|------|------|
| 3~4 | 扁平，廉价 | 模板阶段 |
| 6~8 | 有立体感 | 简单物品 |
| 9~11 | 精致，丰富 | 武器/工具（标准） |
| 12+ | 极丰富 | 特殊物品 |

## 自定义配色工作流

### 第一步：确定色调和风格关键词

```
用户: "血腥风格"
→ AI 推断: 深红为主，暗红轮廓，鲜红高光
→ 建议色阶:
   outline: #2e0a0c
   shadow:  #5e1216  
   body:    #9e1a20 ~ #c82830
   highlight: #f05a5a
```

### 第二步：用 fill_material 生成

```json
POST /api/fill_material
{
  "material": "custom",
  "color": [150, 25, 30],
  "ref_path": "D:/.../G_杂项/iron_sword.png"
}
```

### 第三步：查看效果，微调

生成后调用 `/api/preview` 查看色块。调整 color 值直至满意。

## 渐变公式

`fill_material` 内部将参考图的亮度映射到目标配色的公式：

```
b = 参考图像素的灰度 (0~255)
→ 映射到目标色阶
  outline zone (b < 40):   target = color × 0.2
  shadow zone  (b 40~80):  target = color × 0.5  
  body zone    (b 80~170): target = color × 0.75 ~ 1.0
  highlight    (b > 170):  target = color × 1.15 ~ 1.35
```

如果要**手动控制每个色阶**（不依赖公式），拆成多次 fill：

```json
// 先填轮廓层
// 再填暗面层
// 最后填高光层
// 可以自己控制每个层次的精确 RGB
```
