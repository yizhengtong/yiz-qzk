## 物理文件位置

所有纹理文件存放在 `GUI/` 文件夹下（与项目根目录同级），按用途分两个子目录：

### `GUI/description/` — 通用积木块（原件）

| 文件 | 类别 |
|------|------|
| `border_corner_tl/tr/bl/br.png` | 窗口框架 |
| `border_edge_top/bottom/left/right.png` | 窗口框架 |
| `fill_white.png` | 面板填充 |
| `split_bar.png` | 面板填充 |
| `slot_default.png` | 槽位 |
| `player_slots_9x4.png` | 背包 |

> 此目录为原件保护区，禁止修改。需要使用时必须复制到工作目录。

### `GUI/Tools Container GUI/` — 工作容器特征积木块（工作副本）

| 文件 | 类别 |
|------|------|
| `brewing_stand_potion_slot.png` | 槽位 |
| `brewing_stand_ingredient_slot.png` | 槽位 |

| `brewing_stand_arrow.png` | 进度动画 |

> 所有路径均相对于项目根目录，`GUI/` 文件夹可整体迁移到任意工作区。

### 拼装时的纹理引用

在代码（Screen）中拼装GUI时，需要将纹理文件复制到 `src/main/resources/assets/yizmodqzk/textures/gui/container/` 目录下，然后通过 `ResourceLocation` 加载：

```java
private static final ResourceLocation TEX_SLOT = ResourceLocation.fromNamespaceAndPath(
    "yizmodqzk", "textures/gui/container/slot_default.png"
);
```
