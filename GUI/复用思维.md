# 复用思维 — 框架不变，内容可换

> 核心思维：GUI 的边框/背景/背包是固定框架，中间内容区的图片可以按页切换、按需插入。

---

## 思维模型

```
┌── 固定框架（永远不变）─────┐
│                            │
│  ┌── 可变内容区 ──────┐   │
│  │                    │   │  ← 这一块的内容可以：
│  │  第1页: 剑天赋树    │   │     · 翻页替换（→ 第2页）
│  │  第2页: 盾天赋树    │   │     · 滚动展示（↓ 更多项）
│  │  第3页: 弓天赋树    │   │     · 插入图片（叠加图标）
│  │                    │   │
│  └────────────────────┘   │
│                            │
│  ◀ 1/3 ▶                  │  ← 翻页控件
│                            │
├────── split ───────────────┤
│      player_slots          │
└────────────────────────────┘
```

**关键认知**：不是"做 3 个不同的 GUI"，而是"做 1 个 GUI，内容区插入 3 组不同的图片"。

---

## 三种插入方式

### 方式 A：翻页替换

整个内容区一次性替换为一组新图片。

```
第1页内容: [剑图标] [力量图标] [重击图标] ...
第2页内容: [盾图标] [抗性图标] [铁壁图标] ...
第3页内容: [弓图标] [速度图标] [精准图标] ...

翻页时 → 清空内容区 → 插入下一页的所有图片
```

**适用**：分类标签页（战斗/生存/魔法），每页内容完全不同

### 方式 B：滚动插入

内容区只显示"视口"内的图片，滚动时新图片从边缘滑入。

```
视口可见:  [项目5] [项目6] [项目7]    ← 当前可见的
视口外:    [项目1~4]（上方，已滚过）     ← 在视口外
视口外:    [项目8~20]（下方，待滚入）    ← 在视口外

滚动时 → 上方图片移出视口 → 下方新图片移入视口
```

**适用**：长列表（天赋列表 > 一屏高度），内容同质但数量大

### 方式 C：条件插入

根据状态在已有布局上叠加/替换图片。

```
基础布局: [槽位] [槽位] [槽位]

状态 A → 第1槽插入 [剑图标]，第2槽插入 [空白]
状态 B → 第1槽插入 [盾图标]，第2槽插入 [★激活边框]
状态 C → 第1槽插入 [弓图标]，第2槽插入 [↑升级箭头]

同一位置，不同状态插入不同图片
```

**适用**：同一页面内根据数据状态切换图标（选中/未选中、激活/未激活、0级/1级/满级）

## 翻页的具体实现

### 翻页控件

```
翻页方式 A: ◀ 页码  ▶          ← 左右箭头 + 页码
  积木: sort_up / sort_down（紧凑三角）或 Page left / page right（大型箭头）

翻页方式 B: [战斗] [生存] [魔法]  ← 标签页按钮
  积木: slot_default + 文字 或 effect_background + C_母模板填色图标

翻页方式 C: ▲ 和 ▼ 分页按钮     ← 上下翻页（适合竖直列表）
  积木: sort_up（上翻页）、sort_down（下翻页）
```

### 翻页时的图片替换流程

```
1. 记录当前页号
2. 用户点击翻页按钮 → pageIndex++ 或 pageIndex--
3. 清空内容区的所有图片引用
4. 根据 pageIndex 查找对应的图片组
5. 将新图片组插入内容区（坐标不变，图片引用变）
6. 更新页数显示（"2/5"）
```

## 能用已有积木实现的部分

| 需求 | 已有积木 | 用法 |
|------|---------|------|
| 翻页按钮 | `sort_up` `sort_down` | 左右/上下翻页箭头 |
| 翻页按钮（大） | `Page left` `page right` | 更显眼的翻页 |
| 标签页底框 | `slot_default` | 每个标签的底座位 |
| 标签选中态 | `border_on` | 当前选中标签高亮 |
| 列表项底框 | `slot_default` | 每个列表项的底座位 |
| 列表项激活 | `border_on` | ON 状态 |
| 列表项未激活 | `border_off` | OFF 状态 |
| 内容区背景 | `fill_white` | 可变内容区底色 |
| 分隔 | `split_bar` | 内容区与背包之间 |
| 进度条 | `red_progress` | 翻页进度/加载进度 |

## 自检

设计可翻页/可滚动的 GUI 时：

- [ ] 框架部分（边框+背景+背包）是固定的，不随翻页改变？
- [ ] 可变内容区的图片是按页/按状态分组的？
- [ ] 翻页时是"替换图片引用"而不是"重建整个 GUI"？
- [ ] 翻页控件的位置固定在内容区外侧，不随内容滚动？
- [ ] 新增一页内容只需添加一组图片数据，不需要改框架代码？
