# 05 — 图标与标识

> 用图像说明含义。核心功能：一眼看懂"这是什么东西/什么状态"。

### 状态效果图标 (18×18, 原版全量)
`strength.png` `speed.png` `resistance.png` `absorption.png` `health_boost.png`
`poison.png` `wither.png` `nausea.png` `slowness.png` `haste.png` ...
以及全量原版药水/不祥/试炼效果图标。
直接用于状态面板 → 每个效果对应一个图标。
用于天赋树/属性面板 → 表达对应属性概念（力量=攻击力，抗性=防御）。

### 分类图标 (32×32)
`attack.png` — 战斗/攻击系。红白配色，剑形交叉。
`defense.png` — 防御/护甲系。蓝色层层护盾形。
`mechanic.png` — 工程/机械系。蓝绿齿轮结构。
`passive.png` — 被动/潜行系。黄红对称形。
`recovery.png` — 回复/治疗系。青绿十字/水滴形。

### HUD状态图标
`armor_empty/half/full.png` (9×9) — 护甲值三级。可用于属性面板表达防御等级。
`food_empty/hunger/full/food_full_hunger.png` (9×9) — 饱食度状态。
`air.png` / `air_bursting.png` (9×9) — 氧气/水下呼吸。
`exp.png` / `exp_bg.png` — 经验指示。

### 心形生命值
`heart.png` / `heart_pop.png` — 生命心形(满/空/半)。
`absorbing_full/half.png` — 吸收心(满/半)。
`frozen_full/half.png` — 冰冻效果心。
`poisoned_full/half.png` / `withered_full/half.png` — 中毒/凋零效果心。

### 快捷栏 HUD
`hotbar.png` (182×22) — 快捷栏整体背景。
`hotbar_selection.png` (24×23) — 选中格高亮框。
`hotbar_offhand_left.png` (29×24) — 副手槽(左手布局)。
`hotbar_attack_indicator_*.png` (18×18) — 攻击冷却指示器。

### 攻击/伤害
`damage.png` / `critical_hit.png` — 伤害/暴击指示。
`enchanted_hit.png` — 附魔命中效果。
`block_mined.png` (18×18) — 挖掘进度 / 拆除进度。
