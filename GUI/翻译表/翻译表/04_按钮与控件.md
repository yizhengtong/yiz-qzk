# 04 — 按钮与控件

> 可点击区域、交互反馈、选择器。核心功能是"触发动作"。

### 标准按钮
`button.png` (普通) + `button_highlighted.png` (高亮) + `button_selected.png` (选中)
约20×20。一张底图+半透明遮罩可得全部状态。
`button_disabled.png` — 禁用态。

### 工具按钮
`locked_button.png` / `locked_button_highlighted.png` — 锁定态。
`unlocked_button.png` / `unlocked_button_highlighted.png` — 解锁态。
`report_button.png` / `report_button_highlighted.png` — 举报/报告。

### 筛选器
`filter_enabled.png` / `filter_disabled.png`（各含高亮态）— 筛选开关。

### 排序/翻页
`sort_up.png` (▲18×18) / `sort_down.png` (▼18×18)
变换复用：
- 旋转90° → 指向左右
- 间隔排列 → 分页指示
- 镜像 → 方向互换

### 翻页箭头（大）
`Page left.png` (23×13) / `page right.png` (23×13)
比sort更大更醒目。适合作为主要翻页控件。

### 流程指示
`process_plus.png` (13×13) — 加号。合成/添加/加点。
`result_arrow.png` (22×15) — 指向箭头。输入→输出引导。
`brewing_stand_arrow.png` (7×26) — 竖直箭头。酿造/竖直流程。

### 搜索框
`search_box.png` (90×12可拉伸) — 搜索/输入框背景。

### 教程提示
`Click the left button.png` (32×32) / `Right Click Key.png` (32×32) — 鼠标操作提示图标。
仅用于教学/引导类 GUI。
