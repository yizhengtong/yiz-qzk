## 填色示例

```python
v = ImageViewer()
blank = QImage(16, 16, QImage.Format_ARGB32)
blank.fill(QColor(0, 0, 0, 0))
v.load_image(blank)

# 用铁剑参考图的明暗结构，换水晶蓝色，带凹槽
v.fill_material('custom', [150, 210, 240],
    ref_path=r'...\G_杂项\iron_sword.png',
    groove=55)
v.save_full(r'...\F_生成\result.png')
```
