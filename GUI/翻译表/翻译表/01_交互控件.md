# 翻译表 01 — 交互控件

> 按钮、开关、进度、搜索、标签。同一种框（border_*）可作高亮/开关/标签/节点框。
> 查找思维：我需要哪种交互效果 → 哪张图能改一下实现。

---

### border_on.png
- **尺寸**: 28×28 | **类别**: 状态框 | **颜色**: 品红
- **变换复用**: 缩放→小标记│切片取边→高亮下划线│旋转→角标
- **语义**:
  | 语境 | 含义 |
  |------|------|
  | 容器 | 当前选中/高亮态 |
  | 天赋节点 | 可解锁/已解锁节点边框 |
  | 标签页 | 当前页选中态 |
  | 开关 | ON 状态 |
  | 设置 | 已勾选 |

### border_off.png
- **尺寸**: 28×28 | **类别**: 状态框 | **颜色**: 灰蓝
- **变换复用**: 同 border_on，表示未选中态
- **语义**: 未选中 / 未解锁 / OFF / 未勾选

### accept.png
- **尺寸**: 18×18 | **类别**: 确认 | **颜色**: 绿色勾
- **变换复用**: 缩小→选中标记点│旋转→取消标记
- **语义**: 确认 / 加点确认 / 保存应用

### cross_button.png
- **尺寸**: 14×14 | **类别**: 取消
- **语义**: 关闭 / 取消 / 重置

### cancel.png
- **尺寸**: ~18×18 | **类别**: 取消
- **语义**: 取消按钮（原版变体）

### sort_up.png / sort_down.png
- **尺寸**: 18×18 | **类别**: 排序/翻页
- **变换复用**: 旋转90°→右/左箭头│拉伸→装饰分隔线│镜像→菱形指示
- **语义**: 升降序 / 翻页 / 数值调节

### red_progress.png
- **尺寸**: 182×5（水平拉伸） | **类别**: 进度条 | **颜色**: 红色
- **变换复用**: 旋转90°→竖直进度│切片×3→分段进度
- **语义**: 烧炼 / 血量 / 加载 / 经验 / 天赋升级

### blue_progress.png
- **尺寸**: 182×5 | **类别**: 进度条 | **颜色**: 蓝色
- **语义**: 同 red 结构，蓝色版。魔力/经验/水相关进度。

### burn_progress.png / brew_progress.png
- **尺寸**: ~14×14 | **类别**: 进度 | **语义**: 熔炉燃烧/酿造进度

### button.png / button_disabled.png / button_highlighted.png / button_selected.png
- **尺寸**: ~20×20 | **类别**: 按钮四态
- **语义**: 普通/禁用/高亮/选中。用 1 张 + 半透明遮罩可得其他态。

### search_box.png
- **尺寸**: 90×12（拉伸） | **类别**: 搜索框 | **语义**: 拉伸至内容区宽

### blue_marker.png
- **尺寸**: ~10×10 | **类别**: 标记 | **语义**: 蓝色选中标记

### 标签页系列
- **保留**: `tab_above_left.png` + `tab_above_left_selected.png`
- **变换复用**: 旋转90°→侧标签│水平翻转→右标签│垂直翻转→下标签
- **语义**: 2 张覆盖全部 12 个方向的标签页

### 横幅 / 复选框 / 筛选器
- **语义**: 详见各条目。此类控件大多可一图多用（+遮罩/高亮）

### 数字标记 1~5
- **尺寸**: ~8×8 | **类别**: 数字 | **语义**: 等级/序号标记

### 旗帜标记
- **尺寸**: ~16×16 | **类别**: 标记 | **语义**: 多色旗帜，分类/筛选/队伍标识
