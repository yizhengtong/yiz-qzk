# 02 — 槽位与背包

> 放东西的格子。核心功能是"承载"，延伸功能是"占位/状态/轨道"。

### slot_default.png (18×18)
标准物品槽。默认网格单位。
变换复用：
- 间隔排列 → 进度条轨道/菜单列表
- 水平密排 → 装饰分隔线
- 半幅遮罩 → 半满/进度状态
- 叠色 → 禁用/锁定状态

### player_slots_9x4.png (162×76)
预装背包组件：36格(9×4) + 9格快捷栏。容器 GUI 底部固定，不可替代。
列对齐基准：所有容器列宽以此为准(9列×18px=162px)。

### 变体槽位
`brewing_stand_potion_slot.png` (18×18) — 药水瓶专用槽。与slot_default结构相同色调微调。
`brewing_stand_ingredient_slot.png` (18×18) — 材料专用槽。
