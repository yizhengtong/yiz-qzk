# 翻译表 01 — 交互控件

> 按钮、开关、排序、进度条、搜索框、标签页、标记等通用交互元素。

---

### border_on.png
- **尺寸**: 28×28 | **类别**: 状态框
- **颜色**: 品红色边框
- **语义**:
  | 语境 | 含义 |
  |------|------|
  | 容器槽位 | 当前选中/高亮态 |
  | 天赋/技能节点 | 可解锁/已解锁节点边框 |
  | 开关组件 | ON 状态 |
  | 设置选项 | 已勾选 |

### border_off.png
- **尺寸**: 28×28 | **类别**: 状态框
- **颜色**: 灰蓝色边框
- **语义**:
  | 语境 | 含义 |
  |------|------|
  | 容器槽位 | 未选中/普通态 |
  | 天赋/技能节点 | 未解锁节点边框 |
  | 开关组件 | OFF 状态 |
  | 设置选项 | 未勾选 |

### accept.png
- **尺寸**: 18×18 | **类别**: 确认
- **颜色**: 绿色勾
- **语义**:
  | 语境 | 含义 |
  |------|------|
  | 确认弹窗 | "确定"按钮 |
  | 合成确认 | 确认制作 |
  | 天赋加点 | 确认加点 |
  | 设置面板 | 保存/应用 |

### accept_highlighted.png
- **尺寸**: 18×18 | **类别**: 确认 | **语义**: 确认高亮态（鼠标悬停）

### cross_button.png
- **尺寸**: 14×14 | **类别**: 关闭/取消
- **语义**:
  | 语境 | 含义 |
  |------|------|
  | 弹窗 | 关闭按钮(×) |
  | 确认对话框 | 取消操作 |
  | 天赋面板 | 取消加点/重置 |

### cancel.png
- **尺寸**: 约 18×18 | **类别**: 取消
- **语义**: 取消按钮（与 cross_button 类似但风格略异，原版取消图标）

### sort_up.png / sort_down.png
- **尺寸**: 18×18 | **类别**: 排序/翻页
- **变换复用**: 旋转90°→右/左箭头│拉伸→装饰分隔线│镜像→菱形指示
- **语义**:
  | 语境 | 含义 |
  |------|------|
  | 列表 | 升序/降序排列 |
  | 翻页 | 上一页/下一页（紧凑型） |
  | 数值调节 | 增加/减少 |

### red_progress.png
- **尺寸**: 182×5 | **类别**: 进度条 | **颜色**: 红色
- **语义**:
  | 语境 | 含义 |
  |------|------|
  | 工作方块 | 制作/烧炼进度 |
  | Boss 血条 | 敌人血量 |
  | 加载界面 | 加载进度 |

### blue_progress.png
- **尺寸**: 182×5 | **类别**: 进度条 | **颜色**: 蓝色
- **语义**: 与 red_progress 同结构，蓝色版。可用于经验值/魔力进度

### burn_progress.png
- **尺寸**: 约 14×14 | **类别**: 进度 | **语义**: 熔炉燃烧进度指示

### brew_progress.png
- **尺寸**: 约 14×14 | **类别**: 进度 | **语义**: 酿造进度指示

### button.png / button_disabled.png / button_highlighted.png / button_selected.png
- **尺寸**: 约 20×20 | **类别**: 按钮四态

### search_box.png
- **尺寸**: 90×12 | **类别**: 搜索 | **语义**: 搜索框背景条，拉伸至内容区宽

- **尺寸**: 约 10×10 | **类别**: 标记 | **语义**: 蓝色选中标记，列表/筛选面板用
