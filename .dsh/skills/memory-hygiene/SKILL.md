# memory-hygiene —— 记忆库初始化（写入闸门）

本 skill 管理的是**自定义记忆库**（用户偏好：记忆 md 不放 C 盘系统盘）。在写或改任何记忆之前，先按下述 8 条纪律自检；每条都是**强制规则**，不是建议。

> ⚠️ **双库路由**：本工作区有模组库（默认 `/mnt/d/ZM/yizgzq/yiz1.21.1/yizjy/`）和股票库（`/mnt/d/ZM/stock-memory/`）。**按当前会话主题选库**，股票主题时写进股票库、不碰模组库。判定与关键词见 AGENTS.md「记忆库（双库 + 主题路由）」。下文「主记忆库目录」在股票主题下应替换为股票库路径。

- **主记忆库目录**：`/mnt/d/ZM/yizgzq/yiz1.21.1/yizjy/` ← 所有记忆 md 正文与主索引都写到这里
- **主索引文件**：`/mnt/d/ZM/yizgzq/yiz1.21.1/yizjy/MEMORY.md`（每条记忆一个 `.md` 子文件 + 索引里一行）
- **C 盘 SDK 自动加载点**：`/mnt/c/Users/Administrator/.proma/agent-workspaces/yiz/.claude/memory/MEMORY.md` —— SDK 固定自动加载路径，**只放一行指针**指向 D 盘主库，不放任何记忆正文（兼顾"记忆不放 C 盘"偏好与 SDK 启动时的自动提醒）。

## 强制清单（写入前逐条核对）

1. **MEMORY.md 只做索引**：每个主题一行，不在索引里堆放正文。
   - 标准索引行：`- [标题](文件名.md) — 一句话钩子`
   - 正文写进对应子文件，绝不把正文/解释塞进 MEMORY.md。

2. **体量软上限**：以 150 行或 20KB 为日常软上限，永不逼近 200 行 / 25KB 的加载上限（同时适用于 MEMORY.md 和单个子文件）。
   - 逼近上限时的处置顺序：先拆分「一个文件塞了多个主题」的文件 → 再瘦身正文（删冗余、压缩措辞）→ 最后把冷主题归档到独立子文件。

3. **单主题**：每个子文件只保存一个明确主题，多个不相关主题不堆在一个文件里。

4. **写入前先检索**：能更新旧记录，就不重复新增。
   - 步骤：先用 Glob/Grep 在 `/mnt/d/ZM/yizgzq/yiz1.21.1/yizjy/` 下搜主题关键词与现有文件名 → 命中相关记录则 Edit 更新，而不是新建文件。
   - 在主索引加行前，先确认是否已有同主题行可更新。

5. **即时纠错**：新结论推翻旧结论时，直接修正旧记录，不保留互相矛盾的两个版本。发现旧记录过时/有误，原地 Edit 改掉，不要新建「更正版」并存。

6. **不抄可重新获得的内容**：Git 历史、代码与代码注释、CLAUDE.md、README、项目文档里已明确存在且容易重新获得的内容，不重复抄进记忆。只记「非显而易见、删掉后未来会重新犯错」的那一层。

7. **秘密禁入**：密码、密钥、Cookie、Token、私钥和其他秘密**永不写入记忆**。无论用户是否要求，遇到这类内容一律拒绝落盘。

8. **按类型分类（不强建空目录）**：记忆类型分 user / feedback / project / reference。
   - `user`：用户是谁（角色、专长、偏好）。
   - `feedback`：用户对 Agent 工作方式的指导（含 **Why:** + **How to apply:**）。
   - `project`：进行中的工作、目标、约束（非代码可推导；相对日期转绝对）。
   - `reference`：外部资源指针（URL、面板、工单）。
   - 仅在当前实现支持类型时分类；不为凑分类强行创建空目录或空文件。

## 标准写入流程

1. **先检索**：Glob `/mnt/d/ZM/yizgzq/yiz1.21.1/yizjy/*.md` + Grep 主题关键词，判断「更新」还是「新增」。（第 4 条）
2. **正文落子文件**：在 `yizjy/` 下一个主题一个文件；frontmatter 含 `name` / `description` / `metadata.type`。（第 3、8 条）
3. **维护索引**：在 D 盘主索引 `yizjy/MEMORY.md` 用一行 `- [标题](文件.md) — 钩子` 指向该文件；新增则加行，更新则改对应行。C 盘 `MEMORY.md` 只保持那一行指针，不重复维护。（第 1 条）
4. **核体量**：写入后估算主索引与该子文件的行数/体积，逼近软上限就按第 2 条处置。
5. **核秘密**：最后扫一遍正文，确认无第 7 条所列内容。
